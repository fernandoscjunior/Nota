# Nota

Nota is a minimalistic, open-source, AI-powered Web DAW (Digital Audio Workstation) where you can learn the basics of musical composition, sound design, and audio production.

## Vision
A radical departure from cluttered, intimidating digital audio workstations. Built with a minimalist tactile aesthetic inspired by Teenage Engineering and Dieter Rams, Nota combines:
- **Zero-Latency In-Browser Audio**: Native Web Audio API + dedicated AudioWorklet synthesizers and drum machines.
- **In-Situ Music Theory**: Learn scale modes, harmonic tension, and Roman numeral chord progressions directly on the canvas.
- **Edge + Cloud AI**: Pitch-to-MIDI transcription via ONNX Runtime Web and generative sound design powered by Azure OpenAI / Phi-4.

See [decisions.md](decisions.md) for full architectural decisions and the roadmap to the Microsoft Imagine Cup 2027.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
